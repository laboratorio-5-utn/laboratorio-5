# Sistema de Reportes de Averías e Incidencias - Help Desk TI

Aplicación web para reportar incidencias de hardware y software, asignarlas a técnicos, registrar seguimientos y consultar estadísticas

## Tecnologías

- HTML, CSS y JavaScript con módulos ES
- Firebase Authentication
- Cloud Firestore
- Cloud Storage
- Firebase Hosting
- Google Charts
